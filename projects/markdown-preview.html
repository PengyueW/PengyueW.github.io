A small itch, scratched.

I write a lot of notes and READMEs in Markdown, and macOS has always handled them badly: Quick Look renders a .json or a .txt nicely but shows a Markdown file as raw text, and opening an editor just to read something or change one word felt like too much. Markdown Peek fixes exactly that and nothing more. It uses only what ships with macOS, with no third-party libraries, and the Markdown renderer is my own, written in Swift.

👀 Rendered in Quick Look ✏️ Edit in the preview 🌗 Light & dark mode 📦 1 MB, universal 🧩 Zero dependencies 🆓 Free
Note: the app is not on the Mac App Store and isn't notarized, so the first launch may be blocked. Right-click it and choose Open, or allow it under System Settings → Privacy & Security.
What it does

Read, edit, close

👀
Space to preview
Works in Finder and on the desktop, wherever Space opens Quick Look. Relative images next to the file are embedded inline, so screenshots in a README show up too.
✏️
Edit without leaving
The Preview / Edit toggle (or ⌘E) swaps the rendered view for a plain-text editor inside the same panel. ⌘S saves, and closing the panel saves whatever you left unsaved.
🪟
A real editor when you need one
The ⧉ button opens the file in a proper document window with Edit, Split and Preview modes (⌘1 / ⌘2 / ⌘3), live preview, autosave, Versions, undo and Find & Replace. It doesn't take over as your default Markdown app.
📝
The Markdown you actually write
Headings, emphasis, strikethrough, inline, reference and bare links, images, block quotes, nested and task lists, GitHub tables, fenced and indented code, rules, inline HTML and YAML front matter.
🌗
Follows your Mac
The preview switches between light and dark with the system appearance, and uses the system fonts, so it looks like it belongs there.
🔒
Careful with your files
The helper that saves your edits only writes to files that already exist and have a Markdown extension, and it coordinates writes so an open editor window picks up the change.
Under the hood

Getting around the sandbox

Rendering was the easy part. Editing was harder: macOS sandboxes every Quick Look extension and gives it read-only access to the file it previews, so the extension itself can never save. It hands the new text over XPC to a small helper agent instead. launchd starts the agent only when it's needed, and it quits again after 30 seconds of doing nothing.

├─ Contents/MacOS/MarkdownPeek                editor app (NSDocument)
├─ Contents/MacOS/MarkdownPeekAgent           on-demand save helper (launchd + XPC)
└─ Contents/PlugIns/MarkdownPeekPreview.appex Quick Look preview extension
LanguageSwift, about 2,000 lines in total
FrameworksAppKit, WebKit, QuickLookUI, Foundation XPC; nothing else

Install it

macOS 12+

Drag Markdown Peek into Applications and open it once. If Space still shows plain text afterwards, click Refresh Quick Look in its window, or check System Settings → Privacy & Security → Extensions → Quick Look.

🤝 Built with Claude, directed by me

As with my other projects, Claude helped with the implementation, and the decisions were mine.

  • I decided on the scope: Quick Look first, editing in place, Apple frameworks only, no Markdown library.
  • I worked out how to save from inside the sandbox, with the XPC agent that launchd starts only on demand.
  • I reviewed the code and tested it on my own notes and READMEs, sending back whatever rendered wrong.
  • I chased the registration problems: Quick Look caches, a second copy of the app claiming .md files, an extension that wasn't enabled.
