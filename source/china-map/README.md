# 华夏五千年 · 历史疆域时间地图

一个零依赖的纯静态网站: 在真实东亚地图上, 用时间轴(公元前8000年 — 至今)驱动展示每一时刻**并存的所有政权疆域**, 以中原王朝为主线, 兼收匈奴、突厥、吐蕃、辽、金、蒙古等周边强权; 时间轴末端为现代中国全图(含台湾岛与海南岛)。

## 运行

无需构建、无需依赖——直接双击打开 `index.html` 即可(或用任意静态服务器, 如 `python3 -m http.server`)。

## 功能

- **疆域色块**: 每个政权一种对比色, 中心标注国号简称(宋、明、清…); 疆界随年代按史实变化(如汉夺河西、唐失陇右、金宋以淮为界、清割外东北), 全部政权共 137 个、边界关键帧 200 余个。
- **边界精化(渲染时自动)**: 手绘概形直接叠画会留缝、重叠、露海、甩碎屑, 故渲染前把当前时刻的全部政权栅格化到 0.15° 网格, 在格上把归属判干净, 再描迹成边界——
  - *归属*: 重叠格归面积小者(飞地小国不被大邻国吞没);
  - *缝合*: 用形态学闭运算认"内缝"——离所有政权都远的无主陆地才算真正的空白(草原、未收录的邻邦), 其余无主陆地无论是窄廊、三国交界的楔形还是海湾死角, 一律缝给最近政权; 完全被围住的区块整块划归四邻, 不留"国中空心";
  - *清屑*: 弥合只在对角相接的掐点(否则描迹会自交成蝴蝶结), 算法切出的碎块并入接壤最长的邻国, 孤悬海外的小岛保留;
  - *平滑*: 描迹 → 按格宽重采样 → Taubin 低通 → Chaikin 切角 → Douglas-Peucker 抽稀。每一步都对遍历方向对称且误差有硬上限, 相邻两国沿共享格线得到的曲线仍逐点重合; 三方交汇的格点被钉住, 三岔口不会各自缩开而露出小三角。
  - 沿海一律贴合 Natural Earth 真实海岸线(向海外扩两格后由陆地剪裁); 刻意保留的拉锯重叠区仍以条纹显示。
- **争议条纹**: 两政权拉锯/交战/归属存争地带以双色斜纹叠加显示(宋金淮南、蒙宋川蜀、清与太平天国、抗战沦陷区等)。
- **时间轴按住放大**: 按住时间轴不动约 0.6 秒即以当前时刻为中心放大一级, 连续按住可一路放大到**以日为单位**(可停在 1234-02-09 蔡州城破当日, 看金末帝完颜承麟半日而亡)。
- **点击政权**: 弹出详情卡——都城、开创者、结局、历年人口(户籍原数+现代估计)、概述、本条来源。
- **左侧浮窗(可拖动)**:
  - *帝王页*: 当前所有在位君主——名讳、庙号、谥号、当前年号及其第几年、生卒、现龄、前后任、印章式头像(程序生成);
  - *政权页*: 并存政权清单+国祚进度条(已历/所余)。
- **播放**: 时间自动前进, 三档速度; 空格暂停; ←/→ 微调。
- **来源·考据**: 弹窗列出全部 20 种文献/数据集与七条精度取舍说明。

## 数据与精度(要点)

- 疆界形状据谭其骧《中国历史地图集》等**手工概化**(示意性质, 不能作县级考据); 底图海岸线/河流/湖泊来自 Natural Earth 1:50m(公有领域)。
- 夏商周年代采用"夏商周断代工程"年表; 前841年以前均为推断。
- 帝王共 538 条记录; 明清两代及重大节点精确到日, 唐宋辽金元多精确到月, 更早为年。
- 人口兼列正史户籍原数与《中国人口史》(葛剑雄)现代估计。
- 详见站内「来源·考据」弹窗。

## 文件结构

```
index.html              页面骨架
css/style.css           样式(暗色·鎏金·古籍风)
js/app.js               引擎: 投影渲染/条纹相交/时间轴按住缩放/浮窗/弹窗
data/basemap.js         底图(由 Natural Earth 50m 数据裁剪简化生成)
data/sources.js         来源文献与精度说明
data/polities_pre.js    政权: 史前文化—战国
data/polities_mid.js    政权: 秦—五代十国
data/polities_late.js   政权: 宋辽金—1949
data/emperors1.js       帝王: 传说时代—五代十国
data/emperors2.js       帝王: 辽宋夏金—1949
```

## 如何构建 (How this was built)

本项目由**王鹏越 (Pengyue Wang)** 主导架构与设计, **Claude** 作为实现助手参与编码。

Claude 负责样板代码生成、单元测试脚手架、以及前端视觉的加速实现; 工程判断由我作出:

- **架构**: 零依赖的约束、"关键帧 + 插值"的疆域变迁模型、历史数据与渲染引擎的分离, 以及
  上文所述的边界精化流水线(栅格化 → 归属 → 缝合 → 清屑 → 平滑), 均由我构思并定案。
- **评审**: 我逐段评审 Claude 交回的代码, 并对照《中国历史地图集》等文献校订其中的疆域与
  纪年数据, 不合设计者退回重做。
- **调试**: 相邻政权的接缝、海岸线对 Natural Earth 底图的剪裁、时间轴按住缩放的手感、
  中心标注的落点——这些不一致与功能缺陷由我定位并修正。
- **引导**: 先做哪个时期、哪项功能, 以及每项功能应当如何表现, 由我决定。
